Vehicle Fuel Log

Enter fuel on the Input tab and the actual odometer every Monday on the Monitoring tab. Daily odometer is computed by ratio and proportion of the fuel used.

How to use this page
  1. Add fuel below: pick the vehicle, the liters, and the dates. The liters are shared equally across the days.
  2. Every Monday, type each vehicle's actual odometer in "Weekly odometer readings".
  3. Monitoring shows each day's fuel and the odometer worked out from it. Bold = a reading you typed; grey italic = computed.
  4. Checks finds mistakes, Maintenance shows which vehicles are due for PM, and Reports gives the monthly summary.
Add fuel by date range

Liters are split equally across the days (From to To, inclusive). Overlapping entries add up.

Weekly odometer readings

Type the actual odometer for the date shown (usually Monday). It saves as you type. Clear a box to remove a reading.

Odometer row: bold = a reading you typed · grey italic = computed from the fuel. Weekend days with no fuel are left blank. Today is highlighted.
